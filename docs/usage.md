# CC98 科目资料检索插件 — 使用说明

## 安装

### Chrome

1. 打开 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目的 `cc98-material-search` 目录

### Edge

1. 打开 `edge://extensions/`
2. 开启左下角「开发人员模式」
3. 点击「加载扩展」
4. 选择本项目的 `cc98-material-search` 目录

## 获取 Access Token

> ⚠️ **重要提示**：CC98 的 localStorage 值有 **4 字符随机前缀**（前端代码用 `.slice(4)` 读取）。插件保存 Token 时会自动检测并去除前缀，但你也可以手动处理。

### 方法一：从浏览器 Local Storage 获取（推荐）

1. 在浏览器中登录 [CC98 论坛](https://www.cc98.org)
2. 按 `Ctrl + Shift + J` 打开开发者工具的 **Console**（笔记本上 F12 常被媒体键占用）
   - 如果提示 `Warning: Don't paste code...`，先手动键入 `allow pasting` 回车
3. 输入以下命令并回车：

```javascript
localStorage.getItem('accessToken')
```

4. 复制输出的整串值（`eyJ` 开头，但前面可能有 4 个字符前缀和 `Bearer `）

```
str-Bearer eyJhbGciOiJSUzI1NiIs...
└4字符┘└Bearer ┘└────── JWT ──────┘
```

5. 在插件设置页**原样粘贴**即可，插件会自己剥掉包装

> ⚠️ 两个实测踩过的坑：
> - 键名是 `accessToken`（驼峰），**不是** `access_token`——写成后者拿到的是 `null`。
> - 值不是裸 JWT，而是「4 字符随机前缀 + `Bearer ` + JWT」两层包装。
>   `lib/token.js` 的 `normalizeToken()` 会反复剥到稳定为止。

### 方法二：从 Application 面板获取

1. `Ctrl + Shift + I` → **Application** → **Local Storage** → `https://www.cc98.org`
2. 找到 `accessToken` 行，双击值复制

### 方法二：通过 OpenID 授权（增强版）

> 此功能为增强版，MVP 暂不支持。

插件将使用 `chrome.identity.launchWebAuthFlow` 走 OpenID 授权码流程，自动获取和刷新 token。

## 使用步骤

### 1. 设置 Token

- 点击插件图标 → ⚙️ 设置
- 在 Token 输入框粘贴 access token
- 点击「保存」，再点击「验证」确认有效

### 2. 搜索科目资料

- 切换到 🔍 搜索标签
- 输入科目关键词，如 `数据结构`、`高数下`、`计网`
- 插件自动展开科目别名（如 `高数下` → `高等数学（二）`、`微积分B`）
- 可选：通过版面筛选下拉框限定搜索范围
- 点击「搜索」或按回车

### 3. 查看帖子与附件

- 搜索结果展示：标题、版面、时间、作者、回复数、点击数
- 点击标题可在新标签页打开原帖
- 点击「📎 查看附件」展开附件列表
- 附件列表显示文件名、类型图标

### 4. 下载附件

- **单个下载：** 点击附件旁的「下载」按钮
- **加入队列：** 点击「入队」按钮，附件进入批量下载队列
- **批量下载：** 在下载标签页查看和管理下载队列

### 5. 管理下载队列

- 切换到 📥 下载标签
- 查看队列状态：等待、下载中、完成、失败
- 暂停/恢复队列
- 重试失败的下载
- 清除已完成的记录

## 科目别名配置

在设置页的「科目别名」区域可以编辑 JSON 格式的映射：

```json
{
  "高数下": ["高等数学（二）", "微积分B", "高数下"],
  "计网": ["计算机网络", "计网"]
}
```

- 键为用户输入的简写/别名
- 值为实际搜索时使用的所有关键词（包含原始输入）
- 搜索时会将所有别名逐个搜索，结果合并去重

## 网络要求

| 场景 | 要求 |
|------|------|
| 校园网内 | 直连即可 |
| 校园网外（有 IPv6） | IPv6 直连 |
| 校园网外（无 IPv6） | 需连接校园 VPN 或使用 WebVPN |

## 常见问题

### Q: Token 过期怎么办？

A: CC98 access token 有有效期（通常数小时）。过期后插件会提示，重新从浏览器获取即可。

### Q: 提示"权限不足"？

A: 部分附件可能需要：
- 回复帖子后才能查看
- 达到一定积分才能下载
- 付费购买

本插件**不会**绕过这些限制。

### Q: 搜索不到结果？

A: 可能的原因：
- 关键词不匹配，尝试使用别名或在科目别名配置中添加
- 版面筛选过窄，改为"全站搜索"
- Token 无效，重新设置

### Q: 下载失败？

A: 可能的原因：
- 附件不存在（原帖作者已删除）
- 权限不足
- 网络问题（非校园网环境）
- Token 过期
