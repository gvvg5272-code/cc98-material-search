# CC98 科目资料检索插件 — 合规说明

## 核心原则

### 1. 只读操作

本插件仅执行以下只读操作：
- 搜索帖子（调用 `GET /Topic/Search`）
- 读取帖子内容和附件信息（调用 `GET /Topic/{id}` 和 `GET /Topic/{id}/Post`）
- 下载有权限访问的附件

**不执行任何写操作**，包括但不限于：
- 发帖、回帖、编辑帖子
- 点赞、收藏、评分
- 修改个人信息
- 发送消息

### 2. 不绕过权限

本插件**不会**绕过任何权限限制：
- 不绕过登录要求（必须提供有效 access token）
- 不绕过验证码
- 不绕过回复可见限制
- 不绕过积分/等级限制
- 不绕过付费附件限制
- 不绕过版面访问权限

当用户权限不足时，插件会明确提示"权限不足"。

### 3. 不硬编码密钥

- 不在前端代码中硬编码 `client_secret`
- 不在前端代码中硬编码任何 API key
- Access token 由用户手动提供，保存在 `chrome.storage.local`
- 增强版的 OpenID 授权码流程需用户提供 `client_id`，`client_secret` 不出现在前端

### 4. 控制频率

- 搜索请求间隔 ≥ 500ms
- 附件下载间隔 ≥ 1000ms
- 单次搜索限制最大页数（默认 ≤ 3 页）
- **不做全站爬取**

### 5. 官方 API 优先

- 使用 CC98 官方 REST API（`api.cc98.org`）
- 不解析不稳定的页面 DOM
- 不使用非公开/未文档化的接口

### 6. 数据存储

- Access token 保存在 `chrome.storage.local`（扩展本地存储，不同步）
- 科目别名配置保存在 `chrome.storage.local`
- 下载队列状态保存在 `chrome.storage.session`（会话级，关闭浏览器后清除）
- **不向任何第三方服务发送数据**

### 7. 网络请求范围

所有网络请求仅限于以下域名：
- `api.cc98.org` — REST API
- `file.cc98.org` — 附件下载
- `www.cc98.org` — 原帖链接（仅打开新标签页）
- `openid.cc98.org` — 认证服务（增强版）

### 8. 用户隐私

- 不收集用户个人信息
- 不追踪用户行为
- 不向任何第三方服务发送数据
- Token 存储在本地，不通过网络传输到非 CC98 域名

### 9. 开源与透明

- 插件源代码公开可审查
- 所有 API 调用可在代码中查看
- 接口分析文档公开（`docs/api-analysis.md`）

## 风险声明

- 本插件仅在用户有权限的情况下下载附件，不对下载内容负责
- Access token 由用户自行保管，泄露风险由用户承担
- 插件的使用需遵守 CC98 论坛的用户协议和相关规定
- 建议用户在使用前阅读 CC98 的服务条款

## 许可证

本项目仅供学习和个人使用。
